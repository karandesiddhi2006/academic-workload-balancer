# 🎓 Academic Workload Balancer

**Smart Deadline Clustering and Academic Workload Analysis System**

A web application designed to help college students organize academic tasks, identify deadline clusters, and understand periods of high academic workload.

## 🎯 Key Objectives

- Manage academic subjects and tasks.
- Track upcoming deadlines.
- Identify clusters of closely spaced deadlines.
- Analyze workload to support better academic planning.

## 🛠️ Technology Stack

**Backend:** Python, Flask  
**Frontend:** HTML, CSS, JavaScript  
**Database:** SQLite, SQLAlchemy

**DevOps & Project Management Tools:**
- Git & GitHub — Version control
- Jira — Agile project management
- PyTest — Automated testing
- Jenkins — CI/CD automation
- Docker — Containerization
- Apache Airflow — Workflow scheduling
- AWS — Cloud deployment and services

## ⚙️ Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/karandesiddhi2006/academic-workload-balancer.git
   cd academic-workload-balancer
   ```

2. Create and activate a virtual environment:

   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.
